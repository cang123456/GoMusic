# MusicGo

一个使用 Go、SQLite 和原生网页技术编写的本地音乐播放器。

## 启动

项目需要 Go 1.25 或更高版本。在项目目录运行：

```powershell
go run .
```

然后打开 <http://localhost:8080>。

## 添加歌曲

- 将歌曲放入 `data/music`，重新启动程序后会自动加入歌曲库。
- 也可以在网页中点击右上角的“添加歌曲”。
- 支持 MP3、WAV、FLAC、M4A 和 OGG，单个上传文件最大 100 MB。

歌曲文件保存在 `data/music`，歌曲名称和默认歌曲设置保存在 `data/music.db`。

## 默认歌曲

首次启动时，程序会自动将扫描到的第一首歌曲设为默认歌曲。播放其他歌曲后，点击“设为默认”即可修改。打开网页时播放器会尝试自动播放默认歌曲；若浏览器拦截有声自动播放，点击中央播放按钮即可。
